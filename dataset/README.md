# sample.csv — synthetic input data for NetPRS

> **Synthetic data.** `sample.csv` was generated by a simulation. It has the structure of the data used in the NetPRS paper (genotypes of a discovery and a validation cohort, AD diagnosis, SNP-gene relations, gene-gene interactions) but contains no real participant, no real SNP and no real gene, and it says nothing about Alzheimer's disease. The ADNI and BICWALZS genotypes and the dbSNP/STRING extracts of the paper cannot be redistributed.

## Contents

| Item | Value |

| Subjects | 1,000: discovery cohort 700 (253 AD), validation cohort 300 (113 AD); AD prevalence 36.6% |
| SNPs | 300 (`snp001`–`snp300`), dosage of the counted allele 0/1/2; 744 missing calls (0.25%) |
| Genes | 120 (`GENE001`–`GENE120`) in 6 modules of 20 genes |

| Gene-gene interactions | 405 undirected weighted edges (336 within modules, 69 between modules) |
| File | 302,734 lines, 7,274,111 bytes, UTF-8, LF line ends |

## Format

One tidy table holds all three inputs of NetPRS (Table I of the paper). The header is `table,id,key,value`; every line is one record.

| `table` | `id` | `key` | `value` |
| :------ | :--- | :---- | :------ |
| `subject` | subject ID | `diagnosis` | 1 = AD, 0 = non-AD (required) |
| `subject` | subject ID | `validation` | 1 = validation cohort, 0 = discovery cohort (optional, default 0) |
| `genotype` | subject ID | SNP ID | dosage of the counted allele: 0, 1 or 2; empty or `NA` = missing call |
| `snp_gene` | SNP ID | gene ID | relation weight > 0 (1 for a dbSNP link) |
| `gene_gene` | gene ID | gene ID | interaction weight ≥ 0 (e.g. STRING `combined_score / 1000`) |

```text
table,id,key,value
subject,S0001,diagnosis,1
subject,S0001,validation,0
...
genotype,S0001,snp001,0
genotype,S0001,snp002,1
genotype,S0001,snp070,          <- missing call
...
snp_gene,snp002,GENE084,1
...
gene_gene,GENE001,GENE011,0.5661
```

Rules (implemented identically by `ReadNetPRSCSV.m` and `netprs.data.read_netprs_csv`):

- Subjects keep the order of their first `subject` row, SNPs the order of their first `genotype` row; genes are sorted.
- A (subject, SNP) pair without a `genotype` row is a missing call. Missing calls are mean-imputed with the discovery cohort after quality control.
- `snp_gene` and `gene_gene` rows are optional. Without SNP-gene relations the genomic network W_G cannot be built and the analysis uses the effects I and P only.
- Each gene-gene edge may be listed once in either direction; duplicated or reciprocal rows keep their maximum weight; self-loops and zero weights add no edge.
- Blank lines, a UTF-8 byte-order mark, CRLF line ends, spaces around fields and fields enclosed in double quotes are accepted. A field must not contain a comma or a double quote. Errors report the line number.

Your own data can be written in the same format (for example from PLINK with a short script) and analysed by setting `Config.CSVFile` (MATLAB) or `--data` (Python).

## How the data were generated

`sample.csv` is the output of the default call of the generator, which exists in both languages and writes byte-identical files:

```matlab
% MATLAB / GNU Octave (folder matlab)
addpath('Function');
[Data, Truth] = GenerateSyntheticData();
WriteNetPRSCSV('../dataset/sample.csv', Data);
```

```bash
# Python (folder python)
python make_sample_dataset.py            # write ../dataset/sample.csv
python make_sample_dataset.py --check    # verify the published file
```

All random numbers come from a portable random generator (64 xorshift64 lanes; `RngStream.m` / `netprs.rng`) that gives bit-identical numbers in MATLAB, GNU Octave and NumPy. Generative model (seed 2024):

1. **Gene-gene network.** 120 genes in 6 modules; a gene pair is linked with probability 0.30 within a module (weight U(0.4, 1)) and 0.01 between modules (weight U(0.15, 0.5)); weights are rounded to 4 decimals.
2. **SNP-gene relations.** Each SNP is related to a random gene with probability 0.9 and, with probability 0.2, to a second gene of the same module.
3. **Genotypes.** Independent Binomial(2, p) with minor allele frequency p ~ U(0.05, 0.5).
4. **Diagnosis.** `logit P(AD) = −1 + Σ a_j (x_j − 2p_j) + Σ c_jk (x_j x_k − 4 p_j p_k) + Σ d_j (x_j − 2p_j)`, with three components that mirror the three effects of NetPRS (modules 1 and 2, i.e. `GENE001`–`GENE040`, are the risk modules):
   - *independent effects* — 8 main-effect SNPs per risk module, a ~ U(0.30, 0.55); `snp208` is a major locus with a = 1.0 (APOE-like);
   - *phenotypic interactions* — 6 epistatic SNP pairs per risk module, |c| ~ U(0.35, 0.60), 65% positive;
   - *genomic interactions* — 2 seed genes per risk module whose signal is propagated on the gene-gene network with the GSSL closed form of Eq. (3), `e = (I + L)^{-1} s`, and passed to the SNPs through the SNP-gene relations, `d = 0.5 · gᵀe / max(gᵀe)`; SNPs of interacting genes therefore share effects (35 SNPs with d ≥ 0.1).
5. **Quality-control defects** (among SNPs without main, epistatic or network effect ≥ 0.05): 3 SNPs with 5% missing calls, 3 rare SNPs (MAF ≈ 0.25%) and 3 SNPs violating Hardy-Weinberg equilibrium; then 0.2% missing calls everywhere.
6. **Cohorts.** Subjects `S0701`–`S1000` form the validation cohort.

`Truth` (MATLAB) / `SyntheticTruth` (Python) returns all generating parameters, including every network effect d_j. With the default analysis, quality control removes the 9 defective SNPs (and 5 SNPs whose discovery-cohort MAF is below 5%), and the first SNP level (−log10 P > 1) contains 13 of the 16 main-effect SNPs, 17 of the 35 SNPs with network effect ≥ 0.1 and 27 of 216 null SNPs.
